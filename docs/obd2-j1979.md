# OBD-II / SAE J1979 (`protocol/obd2.py`)

Full legislated OBD-II — **all ten diagnostic modes** — over any transport. The
transport delivers reassembled service payloads, so there is no AT-command
handling and no ASCII scraping; multi-frame replies (VIN, DTC lists) just work.

## The ten modes

| Mode | Name | Entry point |
|---|---|---|
| 0x01 | Current data (live PIDs) | `read_pid`, `read_supported_pids`, `scan_live_data` |
| 0x02 | Freeze-frame data | `read_freeze_frame` |
| 0x03 | Stored (confirmed) DTCs | `read_dtcs` |
| 0x04 | Clear DTCs & freeze frames | `clear_dtcs` |
| 0x05 | O2 sensor monitoring (legacy K-line) | superseded by 0x06 on CAN |
| 0x06 | On-board monitor test results | `read_monitor_test_results` |
| 0x07 | Pending DTCs (current drive cycle) | `read_pending_dtcs` |
| 0x08 | Control on-board component/system | `request_control` |
| 0x09 | Vehicle information (VIN/CALID/CVN) | `read_vin`, `read_calibration_ids`, `read_cvn` |
| 0x0A | Permanent DTCs | `read_permanent_dtcs` |

## Two ways to call it

**Module functions** take a transport explicitly:

```python
from protocol import obd2
from transport.socketcan import SocketCanTransport

with SocketCanTransport("can0") as t:
    rpm   = obd2.read_engine_rpm(t)        # Value or None
    speed = obd2.read_vehicle_speed(t)
    vin   = obd2.read_vin(t)               # Mode 09 PID 02 (multi-frame)
    dtcs  = obd2.read_dtcs(t)              # ["P0301", "P0420", ...]
    live  = obd2.scan_live_data(t)         # {"Engine RPM": "1726.0 rpm", ...}
```

**The `J1979` bundle** binds one transport and (optionally) a make for DTC lookups:

```python
ecu = obd2.J1979(t, make="Ford")
ecu.supported_pids()                 # {0x04, 0x05, 0x0C, ...}
ecu.read_pid(0x0C)                   # RPM
ecu.live_data()                      # {name: "value unit"}
ecu.stored_dtcs(detailed=True)       # [{"code","definition","category"}, ...]
ecu.pending_dtcs()                   # Mode 07
ecu.permanent_dtcs()                 # Mode 0A
ecu.clear_dtcs()                     # Mode 04, True on 0x44 ack
ecu.vin(); ecu.calibration_ids(); ecu.cvn()
ecu.freeze_frame(0x0C)               # Mode 02
ecu.monitor_test_results(0x01)       # Mode 06 records
```

## Live data (Mode 01)

`read_supported_pids()` walks the support bitmasks (PID 0x00, 0x20, 0x40, …) and
returns the set of supported PIDs. `scan_live_data()` reads every supported PID
that we have a decoder for and formats `{name: "value unit"}`.

Decoders live in `protocol/pids.py` as a data table — the standard J1979 formulas
(the same math the old `obd_formulas.c` got right), kept in one place so backends
and the simulator agree by construction:

```python
_pid(0x0C, "Engine RPM", 2, "rpm", lambda d: (256 * d[0] + d[1]) / 4.0)
_pid(0x05, "Coolant Temperature", 1, "degC", lambda d: d[0] - 40)
```

To add a PID, add one `_pid(...)` row. `decode_pid(pid, data)` returns `None` for
unknown or too-short data.

## DTCs (Modes 03 / 07 / 0A)

All three share a decoder. A DTC is two bytes on the wire; `protocol/dtc.py`
decodes it (`0x01 0x34` → `"P0134"`). `describe_dtcs(codes, make)` attaches
human definitions/categories from the DTC library — see
[dtc-library.md](dtc-library.md).

```python
codes = obd2.read_dtcs(t)                         # ["P0301", ...]
detailed = obd2.describe_dtcs(codes, "Toyota")    # + definition + category
```

## VIN (Mode 09 PID 02) — the multi-frame proof

VIN is the canonical multi-frame payload. `read_vin(t)` sends `b"\x09\x02"` and the
transport hands back the reassembled `49 02 01 <17 ascii bytes>`; we strip the
header bytes and keep the printable ASCII. If this works, ISO-TP works. Feed the
result into the [VIN decoder](vin-decoder.md) to expand it into manufacturer /
year / plant.

## Notes for implementers

- Responses are matched by SID echo (`sid + 0x40`) and, where relevant, the PID
  echo — so a stray frame can't be mistaken for the answer.
- `_parse_dtc_payload` honours the DTC count byte and drops the `P0000` padding.
- Functions return `None` / `[]` on no answer; they never raise for an unsupported
  PID.
